# CPU 共同接口规范 V1.0

1. 基础参数

指令集：LoongArch 32 位指令子集

CPU 数据宽度：32 位

指令宽度：32 位

通用寄存器：32 个，每个 32 位

r0：恒为 0，不允许写入

初始 PC：0x00000000（本课程设计测试约定）

顺序执行时 PC 增加 4

时钟：统一使用上升沿触发时序逻辑

复位：统一采用高电平有效的同步复位（初步约定）

存储器：指令存储器和数据存储器分离

2. ALU 模块接口

模块名：alu

输入：

a：32 位操作数 A

b：32 位操作数 B

alu_op：4 位运算控制码

输出：

- result：32 位运算结果

运算控制码统一使用 rtl/common/cpu_defs.vh 中的定义。

3. 数据存储器模块接口

模块名：dmem

输入：

clk：时钟信号

we：写使能信号

addr：32 位字节地址

wdata：32 位写入数据

输出：

- rdata：32 位读取数据

第一阶段使用 256 × 32 位的简单存储器模型。

按字节编址

初期仅支持 4 字节对齐的 LD.W / ST.W

初期采用同步写入、组合读取

后续再讨论 FPGA 存储器映射与访存等待机制

4. 设计协作规则

两人共同维护公共接口规范。

不允许未经协商擅自修改公共模块接口。

各自负责的模块必须编写 Testbench。

每个模块通过功能仿真后再合并。

CPU 顶层模块和流水线控制接口由两人共同设计。

任何接口调整，需要同步修改本文件。
